# Нужны фотографии

Пока везде стоит компонент `<Placeholder>` — серый блок с сеткой и подписью.
Он держит пропорции реального фото, так что замена на `<Image>` не сломает вёрстку.

| Где | Что нужно | Пропорции |
|---|---|---|
| Герой | бригада на объекте или готовая установка, горизонтальный кадр | ~16:9, минимум 1920px по ширине |
| «About us» | кадр-обложка для видео о компании | 524×270 |
| «Our mission / goal» | кадр-обложка обхода объекта | 524×270 |
| Проекты, 6 карточек | по одному фото на каждый тип работ | 242×158 |
| Баннер «Ready to start a project?» | широкий кадр законченного объекта | ~21:9, приглушается до 40% |
| «Why us» | бригада за работой или собранный щит | 463×250 |
| «GO FUTURE» | съёмка с дрона, пойдёт внутрь букв | горизонтальная, 1440×210 видимая зона |

Логотипы партнёров в блоке «Our partners» — текстовые заглушки `[Partner 1..5]`.

**Стоковые фото не ставить.** Нужны реальные съёмки с объектов.
